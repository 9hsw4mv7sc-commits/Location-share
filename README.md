# Страница добровольной передачи геолокации

## Файлы
- `index.html` — страница, которая запрашивает разрешение браузера и отдельное подтверждение отправки координат.
- `server.py` — небольшой сервер, принимающий координаты.
- `submissions.jsonl` — создаётся автоматически после первой отправки.

## Ограничения
- Нельзя получить GPS без разрешения браузера и явного подтверждения отправки.
- Геолокация работает в современных браузерах на HTTPS (или localhost).
- Это не определяет номер телефона, IMSI/ICCID SIM-карты или местоположение по вышкам.
- Не используйте страницу для скрытого отслеживания. Уведомляйте людей, кто получит координаты.

## Локальный тест
Требуется Python 3.10+.
1. Установите переменную окружения `ADMIN_TOKEN` в длинный случайный секрет.
2. Запустите сервер:
   - macOS/Linux: `export ADMIN_TOKEN='замените-на-длинный-секрет'; python3 server.py`
   - Windows PowerShell: `$env:ADMIN_TOKEN='замените-на-длинный-секрет'; python server.py`
3. Откройте `http://localhost:8000`.

## Просмотр отправленных координат
Запросите `/admin` с заголовком `Authorization: Bearer ВАШ_ADMIN_TOKEN`.
Пример:
`curl -H "Authorization: Bearer ВАШ_ADMIN_TOKEN" http://localhost:8000/admin`

## Публикация
Разместите приложение на хостинге, который поддерживает запуск Python-сервера и HTTPS. Задайте переменную окружения `ADMIN_TOKEN` в настройках хостинга. Не публикуйте токен в HTML, исходном коде или сообщениях. Хостинг может требовать адаптацию команды запуска и настройки порта.
